# Pocket Ferryman

> Every step ferries one unfinished thought across the black water.

A mobile journaling app converts walking distance into a ghost ferry carrying unfinished tasks. If you stop moving, the ghosts whisper and block the screen until you complete a small penance. The ferry has limited rowing power, so you must choose which ghost gets rescued from the afterlife.

## Features
- Step-count ferry progress with animated boat and ghost passenger queue
- Task cards become ghosts that block the UI when ignored
- Penance mini-actions like holding the screen steady to row
- Choose one ghost per week to rescue and convert it into a completed habit

## Stack
- React Native
- Expo
- SQLite
- Lottie

## Getting started
```
npm install; npx expo start
```
